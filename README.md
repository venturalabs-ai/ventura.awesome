**Curadoria enxuta de recursos de desenvolvimento, IA, dados, carreira e produtividade.**

## Classificação

**Curation / Skill Repository.** Não é uma lista oficial nem substitui catálogos comunitários maiores.

## Referência upstream

Inspirado no formato de listas `awesome`, com critérios, seleção e organização próprios.

## Escopo

- aprendizado;
- ferramentas;
- linguagens;
- frontend e backend;
- DevOps/cloud;
- IA e dados;
- carreira e open source.

## Critérios de curadoria

- utilidade real;
- manutenção ativa;
- documentação clara;
- baixo atrito para começar;
- preferência por fontes oficiais.

## Método Ventura

`EXPLORE → COMPILE → REPLAY → REGENERATE`

A seleção validada é registrada para evitar reavaliar os mesmos recursos a cada uso.
